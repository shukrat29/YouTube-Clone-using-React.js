## 🎥 YouTube Clone

A fully responsive YouTube clone built with React that fetches real-time video data using the YouTube Data API. Includes live chat functionality, a dynamic comment section, and smart search suggestions as you type. Designed to deliver an interactive, high-performance user experience similar to the original platform.

---

### 🔥 Features

- 🔍 Real-time search with auto-suggestions
- 🎥 Fetch and display trending & searched videos using **YouTube Data API**
- 💬 Comment section for user engagement
- 🗨️ Real-time chat simulation
- 📱 Responsive UI for mobile and desktop
- ⚡ Fast performance with optimized components

---

### 🛠️ Tech Stack

- **React.js**
- **Tailwind CSS**
- **YouTube Data API**
- **React Router DOM**
- **Redux Toolkit**
